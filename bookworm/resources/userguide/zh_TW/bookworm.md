# Bookworm 使用者指南

## 介紹

Bookworm 是一款文件閱讀器，可讓您透過彈性、簡潔且具有良好無障礙支援的介面閱讀 PDF、EPUB、MOBI 以及許多其他格式的文件。

Bookworm 提供了豐富的閱讀工具。您可以搜尋文件，為感興趣的內容新增書籤、醒目提示和註解，使用文字轉語音朗讀，使用 Bookworm 書櫃管理文件，開啟網頁文章，還可以透過光學字元辨識(OCR)將掃描文件轉換為純文字。

Bookworm 執行在 Microsoft Windows 上，可以良好搭配 NVDA、JAWS 等螢幕閱讀器使用。即使未啟用螢幕閱讀器，Bookworm 也能使用內建的文字轉語音功能自行朗讀內容。

## 功能

* 支援超過 20 種文件格式，包括 EPUB、PDF、MOBI、Microsoft Word 文件、HTML、純文字和 Markdown。
* 支援結構化導覽，可使用單鍵命令在標題、連結、清單、表格、引文和圖片之間跳至。
* 支援全文搜尋，並可自訂搜尋選項，包括使用正規表示式以及按頁碼或章節限定搜尋範圍。
* 提供功能豐富且易於使用的標註工具。您可以新增具名書籤、註解和醒目提示，在各類標註之間快速跳至，並將註解或醒目提示匯出為純文字、HTML 或 Markdown 文件。
* 對於支援圖形轉譯的格式，Bookworm 提供兩種頁面檢視方式：純文字檢視，以及經過完整轉譯且可縮放的圖片檢視。
* 支援光學字元辨識(OCR)，可從掃描文件和圖片中擷取文字。Bookworm 整合了 Windows 內建 OCR、開放原始碼的 Tesseract 引擎、VIVO 通用 OCR 以及百度 AI 雲 OCR 服務。
* 內建網頁文章擷取器，可開啟網址並自動擷取頁面主要文章內容。
* 支援 Wikipedia 快速搜尋，並可在 Bookworm 中開啟 Wikipedia 文章。
* Bookworm 書櫃可用於整理本機文件、匯入文件或資料夾、搜尋標題和已索引內容，並將文件打包供離線使用。
* 對提供目錄的文件格式提供完善的目錄導覽支援。
* 支援使用文字轉語音朗讀書籍，並可透過語音設定檔自訂語音選項。
* 支援使用標準的放大、縮小和重設命令縮放文字。
* 支援將任何文件格式匯出為純文字檔案。

## 安裝

要在您的電腦上安裝並執行 Bookworm，請造訪 [Bookworm 發布頁面](https://github.com/blindpandas/bookworm/releases)，下載最新版本。

目前版本需要 Windows 8.1 或更高版本。Windows 7 及更早版本不受支援。

Bookworm 提供三種版本：

* 適用於 32 位元或 64 位元 Windows 的 32 位元安裝版本
* 適用於 64 位元 Windows 的 64 位元安裝版本
* 可從 USB 隨身碟等可攜式儲存裝置直接執行的可攜式版

如果您的系統中安裝了舊版 SAPI5 語音，並希望在 Bookworm 中使用這些語音，建議安裝 32 位元版本的 Bookworm，或使用 32 位元可攜式版。

選擇合適的版本下載。如果下載的是 Bookworm 安裝版本，請執行 .exe 檔案並按照螢幕提示操作。如果選擇可攜式版，請將壓縮檔解壓縮到任何位置，再執行其中的 Bookworm 可執行檔。

## 用法

### 開啟文件

您可以從「檔案」功能表中選擇「開啟...」，也可以按 Ctrl+O。系統會顯示「開啟檔案」對話框；找到要閱讀的文件並選擇「開啟」，即可將其載入到 Bookworm 中。

在「檔案」功能表中，您還可以按 Ctrl+N 開啟新的 Bookworm 視窗，按 Ctrl+W 關閉目前文件，或按 Ctrl+P 釘選目前文件。釘選文件和最近開啟的文件分別位於對應的子功能表中，也可以從這些子功能表中清除清單。

「檔案」功能表還包含「匯入」子功能表。「匯入 QRD 檔案」可匯入 QRead QRD 檔案中的閱讀位置資訊，並在儲存的位置開啟原始文件。「偏好設定...」用於開啟 Bookworm 的偏好設定，也可以按 Ctrl+Shift+P 開啟。

### 閱讀器視窗

Bookworm 主視窗包含以下部分：

1. 「目錄」：顯示文件章節，便於瀏覽文件結構。使用導覽鍵在章節之間移動，按 Enter 可跳至指定章節。在文字檢視中按 Ctrl+T 可將焦點移到目錄。

2. 「文字檢視」區域：顯示目前頁的文字。您可以使用一般的文字導覽指令閱讀，也可以使用以下鍵盤快速鍵在文件中導覽：

* Enter 或 Space：跳至目前章節的下一頁
* Backspace：跳至目前章節的上一頁
* Page Down 和 Page Up：在目前頁面內向前或向後移動較大部分文字
* 當游標位於第一行時，連續按兩次向上鍵可跳至上一頁。
* 當游標位於最後一行時，連續按兩次向下鍵可跳至下一頁。
* Alt+Home：跳至目前章節的第一頁
* Alt+End：跳至目前章節的最後一頁
* Alt+Page Down：跳至下一章節
* Alt+Page Up：跳至上一章節
* F2：跳至下一個書籤
* Shift+F2：跳至上一個書籤
* F8：跳至下一個註解
* Shift+F8：跳至上一個註解
* F9：跳至下一處醒目提示
* Shift+F9：跳至上一處醒目提示
* Ctrl+Enter：執行目前位置的特殊動作。Bookworm 可跟隨內部連結、在預設瀏覽器中開啟外部連結、在可瀏覽對話方塊中顯示表格，或開啟嵌入圖片。
* Ctrl+Shift+Enter：跟隨內部連結後返回上一個位置。

3. 閱讀進度滑桿：在偏好設定中啟用「顯示閱讀進度百分比」後，Bookworm 會在狀態列顯示閱讀進度，並允許您使用滑桿依閱讀進度百分比在文件中跳至。

### 結構化導覽

當文件包含語意結構時，您可以直接在文字檢視中按元素導覽。按對應字母可移到下一個元素；按住 Shift 再按同一字母可移到上一個元素。

* H：標題
* 1 到 6：1 到 6 級標題
* K：連結
* L：清單
* T：表格
* Q：引述
* I：圖片或圖形

您也可以從「文件」功能表中開啟「元素清單...」，或按 Ctrl+F7。元素清單可顯示標題、連結、清單、表格、引述和圖片。啟用某一項即可跳至對應元素。

### 文件指令

「文件」功能表包含與目前文件相關的指令：

* 「文件資訊...」在相關資訊可用時顯示中繼資料和文件統計資訊。
* 「元素清單...」可按 Ctrl+F7 開啟結構化元素清單。
* 「變更閱讀模式...」可按 Ctrl+Shift+M 開啟閱讀模式對話框。可用模式取決於文件格式，可能包括預設、閱讀順序、實體版面配置、分頁、逐章節、純文字和全文模式。
* 「轉譯頁面...」可在文件格式支援圖形轉譯時按 Ctrl+R 開啟目前頁的完整轉譯圖片。

### 書籤、註解和醒目提示

Bookworm 允許您為開啟的文件新增註解。您可以新增書籤以記住文件中的特定位置，並在日後快速跳至該位置。您還可以新增註解來記錄想法或摘要，並醒目提示選取的文字以便稍後檢視。

#### 新增書籤

閱讀文件時，您可以按 Ctrl+B，或從「標註」功能表中選擇「新增書籤」，在目前游標位置新增書籤。您也可以按 Ctrl+Shift+B，或從「標註」功能表中選擇「新增具名書籤...」，來新增具名書籤。

#### 檢視書籤

進入「標註」功能表並選擇「已儲存的書籤...」，即可開啟書籤清單。啟用清單中的任何項目會立即跳至該書籤所在位置。要在文字檢視中快速在書籤之間跳至，請使用 F2 和 Shift+F2。

在已儲存書籤對話框中，按 F2 可重新命名選取的書籤，按 Delete 可將其刪除。

#### 新增註解

閱讀文件時，您可以按 Ctrl+M，或從「標註」功能表中選擇「新增註解...」。Bookworm 會提示您輸入註解內容。輸入內容並選擇「確定」後，註解會新增到目前位置。如果已選取文字，註解會附加到選取的範圍。

如果希望 Bookworm 在建立註解後詢問標籤，請在新增註解時按住 Shift。

進入含有註解的頁面時，Bookworm 可以播放簡短音效作為提示。此行為可在偏好設定的「標註」頁面中變更。

#### 新增醒目提示

選取文字後按 Ctrl+H，或從「標註」功能表中選擇「醒目提示選取範圍」，即可將所選文字儲存為醒目提示。如果同一選取範圍已被醒目提示，則會移除該醒目提示。如果選取範圍與已有醒目提示重疊，Bookworm 可以延伸已有醒目提示。

如果希望 Bookworm 在建立醒目提示後詢問標籤，請在新增醒目提示時按住 Shift。使用 F9 和 Shift+F9 可移動到下一處和上一處醒目提示。

#### 管理註解和醒目提示

從「標註」功能表中選擇「已儲存的註解...」或「已儲存的醒目提示...」，即可開啟已儲存項目清單。啟用清單中的任何項目會立即跳至對應位置。選擇「檢視」按鈕可開啟對話框，顯示所選項目的標籤和內容。

您可以按標籤、章節或內容篩選已儲存的註解或醒目提示。相關資訊可用時，還可以按日期、頁碼、位置或書籍排序。按 F6 可移到篩選控制項，按 F2 可編輯標籤，按 Delete 可刪除所選項目，按 Ctrl+C 可複製標註文字。

#### 匯出註解和醒目提示

Bookworm 允許您將已儲存的註解和醒目提示匯出為純文字檔案、HTML 文件或 Markdown 文件。

要匯出註解或醒目提示，請按照以下步驟操作：

1. 在「標註」功能表中，進入「已儲存的註解...」或「已儲存的醒目提示...」。
2. 找到「匯出」按鈕並按 Enter，或使用 Alt+X 快速鍵開啟匯出功能表。

您可以根據需要選取或取消選取以下選項：

* 包含書名：在最終輸出檔案中包含書名。
* 包含章節標題：包含標註所在章節的標題。
* 包含頁碼：包含標註所在頁面的頁碼。
* 包含標籤：在輸出中包含標註標籤。

根據需要指定選項後，選擇純文字、HTML 或 Markdown 輸出格式，再選擇檔案的儲存位置和名稱。選取「匯出後開啟檔案」後，Bookworm 會在儲存完成後自動開啟輸出檔案。

### Bookworm 書櫃

Bookworm 書櫃是用於整理閱讀文件的本機文件庫。您可以從「檔案」功能表的「書櫃」子功能表中選擇「開啟書櫃」。您也可以選擇「加入本機書櫃...」，將目前開啟的本機文件新增到書櫃。

新增或匯入文件時，Bookworm 會讓您選擇閱讀清單和收藏，並詢問是否將文件加入全文搜尋索引。偏好設定的「書櫃」頁面中提供了自動將開啟的書籍加入本機書櫃的選項。

本機書櫃包含「最近新增」「正在閱讀」「想讀」「我的最愛」「閱讀清單」「收藏」和「作者」等分類。書櫃視窗的「檔案」功能表允許您按 Ctrl+O 匯入文件、從資料夾匯入文件、搜尋書櫃、打包文件，以及清除無效文件。

在書櫃文件清單中：

* 按 Enter 可在新的 Bookworm 視窗中開啟選取的文件。
* 當可重新命名時，按 F2 可重新命名選取的文件。
* 按 F5 可重新整理清單。
* 按 Ctrl+F 可將焦點移到快速篩選欄位。
* 焦點位於文件清單時直接輸入文字，可按標題篩選。
* 按 Alt+Left 可從巢狀資料夾或容器返回上一層。

書櫃快顯功能表可在 Bookworm 中開啟文件、使用系統檢視器開啟文件、編輯標題、顯示文件資訊、選擇「編輯閱讀清單/收藏...」、切換「正在閱讀」「想讀」或「我的最愛」狀態，以及從書櫃中移除文件。

「搜尋書櫃...」指令會搜尋文件標題和已索引內容。您可以從搜尋結果直接開啟相符的文件，並跳至相符內容所在的頁面和位置。

### 開啟網址與 Wikipedia

Bookworm 可以將網頁當作可讀文件開啟。從「Web 服務」功能表中選擇「開啟網址」並輸入網址，或按 Ctrl+Shift+U 開啟剪貼簿中的網址。Bookworm 會載入頁面，並盡可能擷取網頁主要內容。網頁支援純文字和全文等閱讀模式。

「Wikipedia 快速搜尋」指令位於「Web 服務」功能表中，也可以按 Ctrl+Shift+W 開啟。如果已選取文字，Bookworm 會將其作為搜尋字詞。您可以選擇 Wikipedia 語言、檢視摘要，並在 Bookworm 或瀏覽器中開啟文章。選取文字時，快顯功能表中還會出現「使用 Wikipedia 查詢定義」。

## 光學字元辨識(OCR)

Bookworm 可以使用 OCR 功能從圖片和掃描文件中擷取文字。這尤其適合將圖片型 PDF 或文件圖片轉換為可閱讀、可搜尋的文字。Bookworm 支援多個 OCR 引擎，您可以根據需要選擇最合適的引擎。

您可以從功能表列的「OCR」功能表造訪 OCR 功能。主要功能包括：

* 「掃描目前頁面...」（F4）：對文件的目前頁面執行 OCR。
* 「自動 OCR」（Ctrl+F4）：在您切換到新頁面時自動執行 OCR。
* 「變更 OCR 選項...」：變更目前書籍的 OCR 選項。
* 「掃描至文字檔...」：掃描頁面並將辨識出的文字儲存到 .txt 檔案。
* 「圖片轉文字...」：選擇電腦中的圖片檔案，並將辨識出的文字當作虛擬文件在 Bookworm 中開啟。

OCR 選項對話框允許您選擇主要辨識語言；當所選引擎支援多語言辨識時，還可以選擇次要辨識語言。您也可以更改提供給 OCR 引擎的圖片解析度、啟用影像增強，並使所選設定在關閉目前書籍前持續套用。

可用的影像前處理濾鏡包括提高影像解析度、二值化、將包含兩頁的掃描圖片拆分為單頁、合併圖片、模糊、傾斜校正、侵蝕、膨脹、銳化和反轉色彩。可用濾鏡和引擎特定選項取決於所選 OCR 引擎。

Bookworm 支援以下 OCR 引擎：

### Windows 10/11 OCR

如果您使用 Windows 10 或更高版本，Bookworm 可以使用作業系統內建的 OCR 引擎。該引擎在可用時是預設引擎，無需額外設定。對於系統中已安裝的語言，它通常能提供良好的辨識結果。

### Tesseract OCR 引擎

對於需要更廣泛的語言支援的使用者，Bookworm 支援整合 Tesseract OCR 引擎。Tesseract 是由 Google 維護的功能強大開放原始碼的 OCR 引擎。

如果尚未為 Bookworm 安裝 Tesseract，您可以在應用程式內下載並設定：

1. 進入「檔案 > 偏好設定...」，選擇「OCR」頁面。
2. 在「Tesseract OCR 引擎」區域中，按一下「下載 Tesseract OCR 引擎」按鈕並按照提示操作。
3. 安裝完成後，您可以按一下「管理 Tesseract OCR 語言」按鈕來管理語言。

### VIVO 通用 OCR 引擎(透過 NVDA-CN)

透過與 VIVO(vivo.com.cn)和 NVDA 中文社區(NVDACN)的合作，Bookworm 提供免費的 VIVO OCR 引擎，可高品質辨識中文及英文內容。

要使用 VIVO OCR 引擎，您需要一個免費的 NVDA-CN 帳號。

#### 設定 VIVO OCR

1. 前往 NVDA-CN 註冊頁面建立帳號：[https://nvdacn.com/admin/register.php](https://nvdacn.com/admin/register.php)。
2. 按一下驗證電子郵件中的連結完成電子郵件驗證。
3. 透過「檔案 > 偏好設定...」或 Ctrl+Shift+P 開啟 Bookworm 偏好設定。
4. 轉到「OCR」設定頁面，在「VIVO OCR 引擎」區域輸入使用者名稱與密碼。
5. 在「預設 OCR 引擎」清單中選擇「VIVO OCR」作為預設 OCR 引擎。

設定完成後，Bookworm 會使用 VIVO 引擎執行 OCR。帳號相關問題可聯絡 NVDA-CN 團隊：support@nvdacn.com。

### 百度 AI 雲 OCR

Bookworm 整合了百度 AI 雲 OCR 服務，在處理中英文混合或複雜版面配置時可提供較高的辨識準確度。該線上服務提供標準與高精確度兩種引擎。

要使用百度 OCR 引擎，您需要取得免費的 API Key 與 Secret Key。

#### 設定百度 OCR

1. 在[百度 AI 雲 OCR 頁面](https://ai.baidu.com/tech/ocr/general)註冊帳號並取得金鑰。
2. 透過「檔案 > 偏好設定...」或 Ctrl+Shift+P 開啟 Bookworm 偏好設定。
3. 轉到「OCR」設定頁面，在「百度 OCR 引擎」區域輸入 API 津要 與 Secret Key。
4. 在「預設 OCR 引擎」清單中選擇「百度通用 OCR（標準）」或「百度通用 OCR（高精確度）」。

設定完成後，Bookworm 會使用百度引擎執行 OCR。

### 朗讀

Bookworm 可以使用系統中已安裝的 TTS 語音朗讀目前文件。按 F5 開始朗讀，按 F6 暫停或繼續朗讀，按 F7 停止朗讀。

您可以透過兩種方式設定語音：

1. 使用語音設定檔：語音設定檔包含自訂的朗讀設定，您可以隨時啟用或停用。可從「朗讀」功能表開啟語音設定檔，也可以按 Ctrl+Shift+V。Bookworm 內建了一些示例語音設定檔。
2. 全域語音設定：未啟用語音設定檔時，Bookworm 預設使用這些設定。您可以在應用程式偏好設定中設定全域語音設定。

朗讀過程中，按 Alt+Left Arrow 可跳至上一個段落，按 Alt+Right Arrow 可跳至下一個段落。

### 媒體按鍵行為

媒體按鍵可用於執行主要的文字轉語音操作：

* 播放/暫停：切換 TTS 的播放、暫停及繼續。
* 下一首：跳至下一個段落。等同於 Alt+Right Arrow。
* 上一首：跳至上一個段落。等同於 Alt+Left Arrow。

預設情況下，只有當 Bookworm 視窗擁有焦點時，媒體按鍵才由 Bookworm 處理。您可以在偏好設定的「閱讀」頁面中選取「啟用全域媒體按鍵」來開啟全域媒體按鍵。這樣 Bookworm 在背景執行時也可以控制播放。

同時執行多個媒體應用程式時，媒體按鍵功能可能不穩定。

### 設定閱讀方式

除了語音設定之外，Bookworm 還允許您微調閱讀行為。以下所有設定都可以在應用程式偏好設定的「閱讀」頁面中找到。

* 按下播放時：此設定決定 Bookworm 開始朗讀目前文件時執行的操作。您可以選擇「朗讀整份文件」「朗讀目前章節」或「朗讀目前頁」。
* 開始朗讀位置：此選項決定從何處開始朗讀。可以從游標位置或目前頁面開頭開始。
* 朗讀期間：這組選項控制 Bookworm 在朗讀過程中的行為。
* 朗讀頁碼：導覽到每一頁時，文字轉語音會讀出頁碼。
* 宣告章節結尾：章節結束時，文字轉語音會進行提示。
* 詢問是否切換至與目前書籍語言相符的語音：當選取的 TTS 語音與目前文件的語言不同時，此選項決定 Bookworm 是否提示您切換語音。
* 醒目提示朗讀中的文字：啟用後，目前朗讀的文字會在介面中醒目提示。
* 選取朗讀中的文字：啟用後，目前朗讀中的文字會被選取。例如，您可以在朗讀過程中按 Ctrl+C 複製目前朗讀的段落。

「閱讀」頁面還包含在文字中導覽時提供圖片回饋的選項，包括導覽到圖片時播放音效，以及在圖片導覽中包含替代文字為空的圖片。

### 連續朗讀模式

除了 Bookworm 內建的文字轉語音功能外，您還可以使用螢幕閱讀器的連續朗讀功能，也稱為「讀出全部」。Bookworm 透過「連續朗讀模式」支援此功能。該模式預設啟用，您可以在應用程式偏好設定的「閱讀」頁面中停用。啟用後，螢幕閱讀器讀到頁面結尾時，Bookworm 會自動翻頁。

請注意以下限制：

* 如果到達空白頁面，連續朗讀會中斷。請移到非空白頁面，再重新啟動螢幕閱讀器的連續閱讀功能。
* 當游標移到目前頁面最後一個字元時，會立即切換到下一頁。

### 檢視目前頁面的完整轉譯版本

當文件支援圖形轉譯時，Bookworm 允許您檢視目前頁面的完整轉譯版本。開啟文件後，可以按 Ctrl+R，或從「文件」功能表中選擇「轉譯頁面...」。該檢視稱為「轉譯檢視」，以區別於預設的文字檢視。

在轉譯檢視中，您可以使用一般縮放指令：

* Ctrl+=：放大
* Ctrl+-：縮小
* Ctrl+0：重設縮放比例

您也可以使用前文提到的文件導覽命令在轉譯檢視中翻頁。按 Escape 可關閉此檢視並返回文字檢視。

當 Ctrl+Enter 開啟嵌入圖片時，圖片對話框提供以下命令：

* Ctrl+=：放大
* Ctrl+-：縮小
* Ctrl+0：實際大小
* Ctrl+S：儲存圖片
* Ctrl+C：複製圖片
* Escape、Ctrl+W 或 Alt+C：關閉圖片對話框

當 Ctrl+Enter 開啟表格時，Bookworm 會在可瀏覽的 HTML 對話框中顯示該表格。

### 前往特定頁面

要跳至目前文件中的特定頁面，請按 Ctrl+G，或從「搜尋」功能表中選擇「前往頁面」，開啟「前往頁面」對話框。輸入頁碼後，Bookworm 會跳至對應頁面。此對話框還會顯示目前文件的總頁數。

對於提供頁面標籤的文件，例如某些 PDF 文件，您可以按 Ctrl+Shift+G，或從「搜尋」功能表中選擇「依標籤前往頁面...」，然後在「依標籤前往頁面」對話框中輸入頁面標籤。

要跳至目前頁面或文件中的某一行，請按 Ctrl+L，或從「搜尋」功能表中選擇「跳至行」。

### 搜尋文件

要在目前開啟的文件中尋找特定字詞或部分文字，請按 Ctrl+F 開啟「搜尋文件」對話框。此對話框允許您輸入要搜尋的文字，並設定搜尋過程。可用選項包括：

* 區分大小寫：搜尋時會考慮搜尋字詞中字母的大小寫。
* 僅比對完整字詞：搜尋字詞必須以完整字詞出現，而不是作為另一個字詞的一部分。
* 正規表示式：將搜尋字詞作為正規表示式處理。啟用此選項時，會停用僅比對完整字詞。
* 搜尋範圍：根據文件情況，您可以將搜尋限制在某些頁面、特定章節或文字範圍內。

在「搜尋文件」對話框中選擇「確定」後，會顯示搜尋結果對話框。啟用清單中的任何項目會立即跳至對應位置，並醒目提示搜尋字詞。

如果您已經關閉搜尋結果視窗，可以按 F3 和 Shift+F3 分別移動到上一次搜尋結果中的下一個和上一個相符項目。

## 管理檔案關聯

應用程式偏好設定「一般」頁面中的「管理檔案關聯」按鈕，可協助您管理要與 Bookworm 建立關聯的檔案類型。建立關聯後，在 Windows 檔案總管中開啟對應檔案時，Windows 會預設使用 Bookworm。此對話框會在首次啟動時顯示，並且僅在安裝版本中可用；可攜式版不提供檔案關聯管理。

開啟檔案關聯管理器後，您會看到以下選項：

* 全部關聯：使 Windows 預設使用 Bookworm 開啟所有支援的檔案類型。
* 取消所有支援的檔案類型關聯：移除之前註冊的檔案關聯。
* 每種支援的檔案類型對應一個按鈕：選擇按鈕即可關聯對應檔案類型。

## 更新 Bookworm

預設情況下，Bookworm 會在啟動時檢查新版本，以便您儘早取得新版本。您可以在應用程式偏好設定中關閉自動檢查，也可以從「說明」功能表中選擇「檢查更新」手動檢查。

無論採用哪種方式，當發現新版本時，Bookworm 都會詢問您是否要安裝。如果選擇「是」，應用程式會下載更新套件，並顯示下載進度對話框。下載完成後，Bookworm 會提示將重新啟動應用程式以完成更新。選擇「確定」即可完成更新過程。

## 回報問題

我們是視障開發者，致力於開發幫助自己和全球視障使用者獨立使用電腦的應用程式。如果 Bookworm 對您有所幫助，也請幫助我們繼續改進。如果您在使用 Bookworm 時遇到錯誤，請在[問題追蹤系統](https://github.com/blindpandas/bookworm/issues/)中提交新問題，並附上錯誤詳細資訊。

提交新 Issue 前，請先在偵錯模式下執行 Bookworm。進入「說明」功能表並選擇「以偵錯模式重新啟動」，然後嘗試重現問題。錯誤再次發生時，Bookworm 通常會顯示包含詳細資訊的對話框；您可以複製這些資訊並附在問題回報中。

有些問題可能難以重現，並且在重新啟動程式後就會消失。在這種情況下，即使沒有偵錯模式的詳細資訊，也可以回報問題。請盡量包含有關系統和使用情境的詳細資訊。
